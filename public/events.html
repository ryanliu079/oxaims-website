What we’ve done

22NovSun

Brasenose College · with OpenAI Student Collective

Website building workshop with OpenAI

Nobody wrote a line of code by hand. After an intro to web development and Codex, we built a website live in five prompts. Then the room split into teams with one challenge: build a website for the best fictional Oxford society, in 40 minutes.

  • Bubble Pop Society
  • Pizza Hunter Society
  • Split Studio
  • Oxford Quantum Computing Society

Four ideas, four working websites, each presented to the room. Thank you to everyone who came, and to the OpenAI Student Collective for partnering with us.
